Addex

Finds which Stremio addons have streams for what you're watching, and shows them right in the stream list with an install link.

Install

Add Addex to Stremio. Open any movie or episode and look for the Addex entries; browse the best addons under Addons, catalog Addex.

Install in Stremio Install via Stremio Web

This server runs over plain HTTP, which the Stremio app's install link can't use: install via Stremio Web or paste the URL into Stremio's addon search.

Personalize

Tick the addons you already have and Addex will stop suggesting them. Your choices are stored in the install URL above, so reinstall after changing them.
